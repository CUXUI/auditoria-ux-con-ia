# Las 5 reglas del stack

Estas son las reglas que comparten todas las skills: cómo se puntúa la severidad,
qué evidencia necesita cada hallazgo, cómo se recorre el producto, cómo se comprueba
cada cosa según la plataforma, y cómo se arma el informe.

**No hace falta instalar ni subir nada de esta carpeta.** Cada skill ya lleva adentro
su propia copia de las reglas que usa. Esto está acá para que puedas leer las cinco
de corrido, sin abrir diez carpetas, y para entender con qué criterio audita la IA.
